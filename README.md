# Project Analytics Bot

Единый Telegram-бот статистики по проектам. Он читает отправки и ответы из
Dialog Hub, а TG-заявки записывает в него заявки на вступление и одобрения.

## Отчёты

- ежедневно в 09:00 МСК — за предыдущий день;
- по понедельникам — недельный отчёт за завершённую неделю;
- первого числа — месячный отчёт за завершённый месяц;
- кнопки: «Эта неделя» и «За всё время».

Первый пользователь, который отправит `/start` боту, автоматически назначается
администратором и чатом для автоматических отчётов. В группе используйте
`/set_report_chat` от имени администратора.

## Интеграция TG-заявок

`approvedApplications.py` отправляет два идемпотентных события в локальный
endpoint: `join_request` (заявка поступила) и `join_approved` (одобрена).
Идентификатор события построен по проекту, пользователю и времени, поэтому
повторная доставка не удваивает статистику.
